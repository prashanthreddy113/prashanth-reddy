# Founder's Daybook

A one-file personal organiser for work, timetable, exercise, diet, startup progress and notes. Open `index.html` in any browser. There is no install and no server.

## Sections

- **Today**: greeting and stats, today's time blocks with the current block highlighted, top tasks with quick add, a Pomodoro focus timer (25/5/15), a weekly habit grid, calories/protein/water, a workout-minutes chart and startup milestones, plus notes you've pinned.
- **Tasks**: To do / In progress / Done board with area (Work, Startup, Study, Fitness, Personal), priority, due dates and filters.
- **Timetable**: weekly plan. Add a block for one day, Mon–Fri, weekends or every day. Shows hours per category.
- **Exercise**: log strength (sets × reps @ kg) or timed workouts. Weekly stats, streak, 14-day chart and personal bests.
- **Diet**: meals by breakfast/lunch/snack/dinner, calorie and protein targets, water glasses, a 7-day calorie chart and a day-by-day history.
- **Startup**: editable name and pitch, key metrics with sparklines and week-on-week change, milestones with progress sliders, and a founder journal of wins, learnings and blockers.
- **Notepads**: colourful sticky notes in six colours on lined paper. Pin notes to Today, change colours, search. Everything saves as you type.
- **Backup**: copy all your data as text and paste it back on another device. You can also clear the example data or erase everything.

Data is saved in the browser's local storage, so each browser keeps its own copy. Use Backup to move data between devices.
