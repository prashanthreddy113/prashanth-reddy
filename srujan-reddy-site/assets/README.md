# Header photos

Drop the two header photos into this folder with exactly these file names:

| File | Shown as |
| --- | --- |
| `rahul-gandhi.jpg` | Rahul Gandhi (left frame) |
| `srujan-kumar-reddy-konda.jpg` | Srujan Kumar Reddy Konda (right frame) |

Square photos (for example 600 × 600 px) look best inside the circular tricolour frame.

Until the files exist the frames show initials, and clicking the 📷 button (or the frame itself)
lets you pick a photo from the device. That photo is saved in the browser only, so committing
the files here is the permanent option.

Use photos you have the right to publish. A freely licensed Rahul Gandhi photo can be found on
Wikimedia Commons (check the licence and credit the photographer).
